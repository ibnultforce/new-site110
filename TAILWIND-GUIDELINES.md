# Tailwind guidelines

How CSS works on this site. Tailwind v4, CSS-first configuration, no
`tailwind.config.js`.

**There is no design system.** Each page designs itself, in its own body, the
way a web designer would build it: any Tailwind utility, arbitrary values, and
its own `<style>` and `<script>` when it needs them. Claude does this for every
page it writes (the brief is `DESIGN_RULES` in `scripts/lib/design-rules.js`),
and it matches the look of a page the site already has (`styleReference`), so
the site still reads as one design.

---

## 1. The setup

| Thing | Where |
| --- | --- |
| Source stylesheet | `styles/main.css` |
| Compiled output — **generated, gitignored, never edit** | `assets/css/main.css` |
| Where classes are scanned from | `templates/`, `content/`, `assets/js/` |
| Compile step | Runs inside `node scripts/build.js` |

```bash
npm install          # required once — Tailwind is a build dependency
npm run build        # builds pages, then compiles CSS, then copies assets
npm run dev          # same, watching styles/ templates/ content/
```

The CSS is compiled **after** pages render, because Tailwind reads class names
out of the templates and content. A class only exists if it's written out in
full in one of the scanned directories: never build one from pieces in a
script (`'bg-' + colour`).

Auto-detection is switched off (`@import "tailwindcss" source(none)`) and the
three source directories are listed explicitly, so `dist/` is never scanned.

---

## 2. What `styles/main.css` holds

Only what every page needs, nothing that decides how a page looks:

- `@theme`: the site's font (`--font-sans`, loaded from Google Fonts in
  `templates/partials/base.html`) and its accent colour (`--color-brand`, so
  `bg-brand`, `text-brand`, `from-brand`, `border-brand/20`…). The header and
  footer use both. Change them to rebrand the site.
- A small base layer: smooth scrolling, the body's default text colour and a
  visible focus outline.
- `.table-scroll`, which the markdown renderer wraps tables in.
- A reduced-motion rule that turns animations and transitions off for people
  who ask their system for less motion.

Don't add page-specific CSS here. A page that needs CSS utilities can't express
puts one `<style>` block at the start of its body, scoped under a class unique
to that page.

---

## 3. Writing a page

- **Anything Tailwind has:** the stock palette, arbitrary values
  (`bg-[#0c2b25]`, `grid-cols-[1.2fr_0.8fr]`), gradients, shadows, rings,
  blur, transforms, transitions and animations.
- **Responsive, mobile first:** every page works at 360px wide with no
  horizontal scrolling; columns split only from `md:`/`lg:` up.
- **Reading text:** wrap long text (an article, a policy) in
  `<div class="prose prose-zinc max-w-none">`, the typography plugin, and adjust
  it with `prose-*` modifiers on that element.
- **Interaction:** one small `<script>` at the end of the body, plain
  JavaScript. The page must read completely without it.
- **Motion:** short, and behind `motion-safe:` where it's an entrance effect.

The markdown renderer keeps an HTML element together up to its closing tag,
blank lines and all, so `<section>`, `<style>` and `<script>` blocks can be
spaced out freely.

---

## 4. Imported pages

`assets/css/imported/*.css` holds an old site's CSS for a page imported with
`edit-page.js --from-html --keep-styles`. Each is scoped to `.imported-page`,
uses `imp-` prefixed classes, and is loaded only by the page whose
`stylesheet` field names it. They're regenerated by converting the page again,
so don't edit them by hand.

---

## 5. Common mistakes

| Symptom | Cause |
| --- | --- |
| A class has no effect | It's built from pieces in a script, or it's in a file outside the scanned sources. Write it out in full and rebuild. |
| A class only works locally | It was added to `assets/css/main.css` by hand. That file is generated and overwritten every build. |
| Content is invisible without JavaScript | CSS hides it before a script reveals it. Let the script add the class that hides it. |
| CSS bundle grows unexpectedly | Something added `dist/` or `node_modules` as a source. Check the `@source` lines. |
| Build fails with "Tailwind CLI not found" | `npm install` has not been run in this checkout or in CI. |
